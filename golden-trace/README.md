# Golden Trace — 独立生成的科研实验准备数据

**用途：为下一步Golden Trace相关科研实验准备教师示范数据。当前仅完成生成与验证，尚未训练学生模型，也未接入已发布的GRPO / PaTR / Tree-Random训练流程。**

这份数据不属于仓库原100题和补充500题的复现结果；不得把示范轨迹的成功率当成Qwen2.5-0.5B训练效果。现有`code/`、配置和结果没有因为本次上传而改变，训练入口不会自动加载此目录。

## 内容

| 文件 | 含义 |
|---|---|
| `golden_traces.jsonl` | 1,000条完整教师轨迹，含任务、地图身份、每步输入/动作/环境反馈和最终消息 |
| `sft_messages.jsonl` | 同一批1,000条轨迹的多轮消息形式，供后续设计SFT实验使用 |
| `summary.json` / `REPORT.txt` | 生成与回放验证汇总 |
| `manifest.json` | 来源数据哈希、任务排除规则、生成协议与环境源码身份 |
| `CHECKSUMS.json` | 本目录文件的SHA256及大小 |
| `verify.py` | 只读校验：逐文件哈希、逐轨迹环境回放、SFT对应关系；不调用教师、不训练 |
| `provenance/` | 当时生成脚本与执行身份记录，仅供审计，不是安装或运行入口 |

## 生成结果与来源

- 生成日期：2026-10-19；发布日期：2026-10-20。
- 1,000条成功轨迹、1,000种不同地图几何；平均4.919步，长度1～10步，无原地移动。
- 生成报告记录全部长度等于环境BFS最短距离；BFS用于候选检查和事后统计，教师输出实际交给原环境执行。
- 显式请求模型`gpt-6.1-sol`、medium推理设置；没有配置模型回退。CLI事件未单独暴露服务端模型标识，因此这里只声明请求身份。
- 教师每回合只输出一个带三反引号的动作，无自然语言推理文本；保留学生侧原始环境提示词，不把教师额外格式指令塞进学生消息。
- 从原10,000条训练任务中筛选候选；生成前排除与验证集、原100题test、补充500题在地图几何上重叠的任务，以及10步内不可解/重复几何。候选不是从测试集抽取。

## 怎么查看与验证

可直接逐行读取两个JSONL文件。完整轨迹与SFT文件按`task_uid`/地图哈希对应；这次只发布数据，不指定训练损失或超参数。

从仓库根目录执行（CPU即可）：

```bash
python -m pip install -r code/requirements-cpu.txt
python golden-trace/verify.py
```

验证使用仓库已冻结的`code/vendor/rllm_source/`环境，并先核对其源码身份。不会修改现有实验、发起模型请求或覆盖任何结果。

`provenance/generate.py`是生成时的原样脚本，包含当时本地目录约定、macOS代理读取以及Codex CLI调用；不是可直接跨平台重跑的生成入口。不要执行它来读取本数据。没有上传虚拟环境、缓存、CLI会话记录或账号配置。

## 后续使用边界

这是教师生成的off-policy示范，可以用于下一步单独的监督学习/辅助目标研究，但不能直接当成当前PPO/GRPO在线采样数据替换进去。训练方案需另行定义，固定基线与评测，分别报告SFT前后和后续RL结果。

数据只含成功示范，候选筛选和成功保留会改变训练分布；目前没有学生模型训练后的效果证据。不要将这1,000条示范成功等同于独立测试100%成功，也不要把它们并入已发表在本仓库的复现成绩。
