## Implementation

The node copies sampled IDs, masks and old logprobs through the first fence in
the current generated turn. It never searches a later block or tests the final
parser result for candidacy. A fence at an exhausted token/context budget is
reported separately: there is no stochastic successor to branch or train.
All eight action-first-token variants are appended to the actual prefix in
unrestricted `prompt_logprobs=1` requests. Their probabilities are summed by
action; residual p[0] is 1 minus that sum. No fence probability is multiplied.

The unchanged consequence stratifier receives the actually observed immediate
successor token. The force request uses the copied prefix and A_cf's allowed
tokens; production continuation follows X. X's old logprob comes from the
unrestricted prompt score, not the restricted force result. The unchanged
last-block parser receives the complete reasoning/fence/action/tail response;
disagreement with X is recorded, never silently corrected or excluded.
Part B starts at X and ends at the end of that generated turn. Prefix masks
are zero; Part A still sees all original sampled tokens.

Selector w, leave-one-out success and baseline, controller calibration, beta,
rho floor, F and HT weighting are reused. CPU suffix invariance checks hold
the calibration inputs fixed. Candidate/p/probability/rho do not depend on the
own suffix **only under that fixed-calibration condition**. This does NOT prove
the required full-pipeline rho invariance; see the counterexample below.
C_o/A_cf necessarily change if the immediate observed action token
changes; they are invariant to later suffix changes. The user explicitly confirmed this test scope: arbitrary suffix changes do
not affect candidate/rho/p; with X held fixed, later changes do not affect C_o/A_cf.

## CPU scope and a second independent blocker

The new functionality tests cover prefix copying/invariance, all eight raw
scores, allowed-token sampling frequency, the original final parser, X's
unrestricted old logprob, Part B mask, and evaluation delegation. The original
v2 suite remains applicable. S05 selection replay uses the recorded feature
inputs and recomputes rho/RNG/decisions/serialized bytes, not missing historical
full-vocabulary probabilities.

`code/ucf/tests/UCF_无偏性模拟_htsim.py` adds a sampled reasoning-prefix/fence
case. The four-action-support case passes with max z=1.4841. A synthetic case
with residual p[0]=0.08 fails with max z=149.4415; Monte Carlo agrees with the
analytically biased estimator (max z=1.9310). This is a mathematical
counterexample, not a measurement of F02's or S15's gradient bias.

Reason: A_cf contains only valid action tokens. For a residual token i in the
STAY class, the original contribution has class-mass weight, but no alternate
sample can supply its complementary contribution. After dividing out the
unchanged common F=2 scale, the missing term is

`p[i] * (1 - P(STAY)) * E[(R_i - b) * grad log p[i]]`.

It need not be zero. The implementation preserves the authorized v2 residual
and fallback rules; it does not repair this by altering strata, dropping p[0],
changing the parser, or relaxing z<4. Consequently functional CPU success is
not overall CPU acceptance, and neither is GPU acceptance. Algorithm revision
requires a new explicit decision. The original four-action htsim is preserved.

Evidence directory: `/data/runs/queue_q35_hard/ucf_v21_20261109/` on the 80GB host.
All raw failure evidence remains there; model weights never leave that host.

## Full-pipeline prefix causality: third independent blocker

The literal test changes only a later turn of the same original trajectory,
adding its first fence. The current node prefix and w=.5, and all other
trajectories, stay fixed. With four candidate weights .5, the unchanged v2
calibrator gives c=1 and current rho=.5. With the additional future candidate,
c=.8 and current rho=.4. Thus the unchanged whole-batch controller violates
the required arbitrary-suffix invariance of rho. This is not a numerical
rounding issue. `prefix_causality.json` records the actual calibrator outputs
and is a mandatory admission gate. The implementation does not silently
substitute a lagged or leave-one-trajectory-out controller: that would change
the explicitly preserved v2 controller and requires an amended definition.
