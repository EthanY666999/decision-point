# 方法、来源和已知限制

## 本次发布对应什么

本次是V1公共训练器＋修订树策略的2026-10-16/17完成版本，不是退化到9%的V4.3。PaTR与Random均从基础模型训练400步，seed42。历史GRPO模型沿用V1已有结果，本轮没有重新训练GRPO；当前trainer/config/data沿用公共底座，可通过GRPO入口独立复跑。

公共部分：Qwen2.5-0.5B-Instruct；单GPU全参数训练；FP32主参数/BF16计算；冻结初始参考模型；vLLM在线采样；按任务、轨迹及长度加权的组相对优势；KL系数0.001；学习率1e-6；10回合；每40步验证。代码也保留DAPO/ARPO分支，但本发布可复现入口只开放已完成对照的GRPO/PaTR/Random，不声明DAPO/ARPO已验收。

PaTR：4初始分支，每5回合路由，选择2条各扩展2个子分支；过程分使用累计奖励加基于BFS距离的归一化进展并裁剪到[0,1]，归一化分母为地图行列数之和减2；分数平局随机打破。对未被扩展分支应用分数剪枝。Random使用随机选择，不使用过程分剪枝。两种树方法均在每轮检查连续6次同动作并剪枝，GRPO和评估不加这一规则。

分数公式等未确定细节是本项目重构选择，不是假称作者已发布的原实现。PaTR和Random不只是选择规则不同，还存在分数剪枝规则差异；本轮实际分数剪枝3次，仍需披露。

## 结果限制

- 全部只有训练seed42。500题bootstrap区间反映题目抽样，不包含训练seed不确定性。
- 原100题主结果PaTR64.5%，Random64.75%；不能据此证明PaTR优于Random或二者等效。
- 事后500题PaTR73%，Random67.1%，配对差+5.9pp、95%区间[2.5,9.4]。它是单独补充分析，不替换原主结果；500题中有91题地图几何在训练集中出现。
- 三个最终模型在主测试均首回合输出无效动作；环境允许无效后继续，故成功率并不等于格式正确率。保留严格解析、原始响应和原始得分，不用补反引号美化结果。
- 响应主要是短动作，不能把本项目约18 sampled tokens直接当作与论文约344 RLen同口径达标。
- 沿用rLLM原环境生成逻辑和V1数据；已知几何重叠、路径长度/生成逻辑限制没有在打包过程中静默修改。数据UID不重叠不保证地图几何不重叠。
- 所有CPU检查、梯度有限、进程完成、checkpoint可加载，都不能替代论文方法忠实性和效果验收。
