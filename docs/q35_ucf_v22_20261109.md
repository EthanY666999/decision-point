## Definition and scope

Future corrected UCF is named **UCF-v2.2**. NoSFT UCF uses **UCF-v2.2-ff**. The user explicitly approved SFT conditional scoring after the opening fence: this is a **third** difference from S05, in addition to question-held-out calibration and full-complement sampling. Historical S05 multiplies fence and action probabilities, uses whole-batch c, and samples only action first tokens. Do not describe these versions as otherwise identical.

For SFT v2.2, the observed opening fence must be at the beginning of the turn (whitespace before it is allowed); a reasoning prefix is not promoted to a SFT candidate. For noSFT-ff, arbitrary sampled reasoning before the first opening fence is allowed. The node ends at the earliest sampled token completing that first fence. No later whitespace token is skipped; no future suffix is inspected. All action-token variants are scored at the observed prefix with unrestricted prompt_logprobs, without multiplying a fence probability. Part B starts with the immediate successor X; copied reasoning/fence masks are0.

Each question's c_k is calibrated using the other questions' eligible candidates and original target/capacity-saturation rule. The original leave-one-trajectory p-hat and baseline are unchanged. The audit fixes all other questions and this question's other three trajectories, changes only trajectory j's suffix, final reward and later candidates, and verifies unchanged c_k and rho for unchanged-prefix nodes on j. The other three trajectories' rho may change as their p-hat includes j. Named controller-v1 and noIS/uniform/HT-cap ablations retain their explicit ablation semantics within the new sampling implementation; the main v2.2 controller is question-held-out.

## Full complement with bounded rejection

The original consequence class includes all action-token variants belonging to it. STAY additionally contains the entire residual vocabulary p[0]. If C_o is STAY, allowed_token_ids lists exactly the finite other-class action variants. Otherwise, one request uses the identical prefix, unrestricted temperature1/top_p1/top_k-1, max_tokens1, n256 and a deterministic seed. Output sample indices define order; the first token outside C_o is selected. No logit_bias is used. Every proposal token/logprob/class-membership and chosen index is retained in compressed rejection logs. All256 in C_o produces the requested fallback, separately counted.

Every accepted X is independently rescored with unrestricted prompt_logprobs. Residual frequency is compared with p[0]/pi_cf using each accepted node's own probability and a summed Bernoulli variance. GPU gates require at least one accepted non-STAY rejection batch, zero forbidden accepted tokens, residual z<4, finite metrics and a nonzero update. Candidate coverage, expected/actual mean forks, exhaustion counts, fallback fractions and cf_parse_mismatch are reported. CPU does not certify GPU execution.

The complement distribution has pi_cf=1-pi_o and unsampled_mass0. **Finite256 exhaustion plus the requested original-only fallback is not an exact unbiasedness guarantee for every possible policy.** Its exhaustion probability for a non-STAY original class is pi_o^256 and depends on that class (e.g.0.99^256≈0.0763). The simulation includes the actual256-proposal algorithm and fallback, records analytic finite-budget bias separately, and checks the requested p[0]=0.08 case. The fallback rule is not silently changed or reweighted.

## NoSFT response protocol and raw replay

All future noSFT methods, including S13/S15/F09/F10 and the later noSFT entries, use the first complete action-block protocol in training and evaluation. The first sampled token completing opening fence + recognized action + closing fence is retained intact, including any inseparable punctuation. Its original token/logprob participates in training and enters the following-turn context. Every subsequent token is discarded. Boundary-token overhang count and fraction are recorded; no retokenization occurs. A context-only mask0 EOS closes a cut assistant turn.

SFT response cutoff stays disabled. Actual disabled SFT IDs, masks, old logprobs, actions and terminal outcomes are tested against the historical function with the real2B tokenizer. Raw S03 full400 and S05 through95 audits show identical visible text/action; hypothetically imposing cutoff would remove sampled EOS, so that hypothetical operation is **not** token-identical. No claim to the contrary is made.
