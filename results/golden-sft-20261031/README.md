# Golden Trace SFT 与 GRPO 和 PaTR 实验结果

2026年10月31日，seed42。Golden Trace 动作监督预热后，GRPO400与PaTR400分别从**同一个SFT模型**独立初始化。PaTR500是PaTR400保留优化器和随机状态的100步续训，已按用户要求停止。

| 模型 | 主100题 Success | 主100题 Pass@4 | 补充500题 Success | 补充500题 Pass@4 |

| 旧PaTR400 | 64.50% | 71.00% | 73.00% | 77.80% |

两套测试分开报告。Success是四次采样的轨迹成功率，Pass@4是至少一次成功的题目比例。原始任务、采样配置及原始输出保持不变；没有补反引号、筛掉失败样本或重新打分。单seed结果；500步预算比400步长，不能单凭这张表断言方法优势。

## 成本和诊断

- SFT：1000条轨迹，19676目标token，63次更新，109.065秒。
- SFT→GRPO400：2334827生成token，578453环境动作，A100运行21549.67秒。
- SFT→PaTR400：1274261生成token，312702环境动作，A100运行12672.79秒。
- PaTR额外401–500：372234生成token，93042环境动作，RTX4090步骤耗时4251.17秒；不含评估、保存和重启开销，与A100时间分开。

采样成本不同，不能称为等算力比较。旧PaTR首回合格式合法率为0%，新模型的格式收益非常明显。成功轨迹长度比较也受成功题集合改变影响；零无效动作条件成功率不能单独证明决策能力提升。状态探针与Tree-Random/GRPO4对照正在新目录执行，本结果包没有这些未完成结果。
